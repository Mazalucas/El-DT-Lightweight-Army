# github-save-release

Complementa `/github-save-small`. Mismas exclusiones que `git-guardar`.

En repo **`mode: canonical`**, ejecutar el flujo de **`git-guardar`** (bump patch + sync + tag). Este skill existe por compatibilidad con el command `/github-save-small`.
