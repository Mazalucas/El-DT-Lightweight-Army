# Bauhaus — Principles

## Form

- Circle, square, triangle as **semantic** anchors (not scatter)
- Thick rules, geometric dividers
- Flat color fields — no gratuitous gradient

## Color

- Primary triad used sparingly: one dominant + neutrals
- Black/white for typography and structure
- Accent rotation per section, not all primaries at once

## Typography

- Geometric sans: Futura, Avenir, Montserrat (use licensed fonts)
- Bold headlines, restrained body
- All-caps headlines OK for short labels only

## Composition

- Overlap shapes with purpose (depth dial 2–3 max)
- Diagonal tension vs static swiss grid
- Photography: b&w or duotone if used

## Product UI Adaptation

- Marketing: full expression
- App chrome: pull back to neutrals + one bauhaus accent
- Never bauhaus buttons on data tables

## Contrast Checklist

- [ ] Body text ≥ 4.5:1 on all backgrounds
- [ ] Primary buttons: white text on saturated fill tested
- [ ] Focus ring visible on geometric buttons
