# Bauhaus Style — Product Shell Template

Uso limitado — preferir Swiss/minimal para product UI densa.

```text
┌──────────────────────────────────────────────────────────────┐
│ ■ App   Section   Section   Section              [ accent ]  │
├──────────────────────────────────────────────────────────────┤
│  Color band (full width) — section title                     │
├──────────────────────────────────────────────────────────────┤
│  Content on white; geometric icons; flat buttons             │
└──────────────────────────────────────────────────────────────┘
```

- Nav: barra sólida (primary-blue o black)
- Estados: cambio de color plano, no sombra
- Reservar bloques de color para secciones, no para cada card
