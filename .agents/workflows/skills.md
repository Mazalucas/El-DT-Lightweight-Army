**Grupo:** Framework DT
**En una frase:** Dejar las skills iguales en todos los IDE — una sola copia canónica.
**Cuándo:** Creaste o editaste una skill, o un IDE no ve una skill que en otro sí.

Ejecutá el skill **`dt-skills`** — `.cursor/skills/dt-skills/` y `.agents/skills/dt-skills/`.
