# Canvas-first (entregas visuales)

Usá canvas (Cursor `.canvas.tsx`, o artifact equivalente del IDE) para **artefactos analíticos grandes** — no para cada respuesta estructurada.

## Cuándo usar canvas

- Auditorías, métricas, billing, comparativas con tablas o charts.
- Planes de `/orquestar` o roadmaps con muchas fases.
- Propuestas A/B con trade-offs extensos.
- Señal: vas a poner **2+ tablas** o **4+ secciones** con headers en el chat.

## Cuándo NO

- Fixes de código, diffs, preguntas cortas, validación no-cómplice.
- Entregables canónicos que viven en `docs/` o PR.

## Cursor

Leer `~/.cursor/skills-cursor/canvas/SKILL.md` antes de escribir `.canvas.tsx`. Ubicación: `canvases/` del workspace Cursor. Chat: 2–5 líneas + link al canvas.

## Fallback

Sin canvas: markdown liviano (máx. 1 tabla, headers solo si 3+ secciones).

## Delegación

Si el subagente entrega análisis grande y hay canvas: pedir `.canvas.tsx` (Cursor) o artifact nativo; chat solo resumen.
