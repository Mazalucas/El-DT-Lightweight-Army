# Glassmorphism — Product Shell

```text
┌──────────────────────────────────────────────────────────────┐
│ rich bg (subtle, darkened)                                   │
│ ┌ glass sidebar ┐  ┌ solid content panel ─────────────────┐ │
│ │ nav items     │  │  tables/charts on OPAQUE surface      │ │
│ └───────────────┘  │  (no glass on data-dense areas)       │ │
│                    └───────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

- Datos/tablas: superficie opaca siempre
- Glass solo: nav flotante, modals, command palette
