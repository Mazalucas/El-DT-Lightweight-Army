# Bauhaus Style — Landing Template

**Dials:** V=7, M=5, D=4 · **Tokens:** `tokens.css`

```text
┌──────────────────────────────────────────────────────────────┐
│ ■ LOGO    nav   nav   nav                         [CTA block]│
├──────────────────────────────────────────────────────────────┤
│ ████████ yellow block │  HEADLINE (display, bold)           │
│ ████████              │  body copy max 2 lines               │
│                       │  [ primary rect ] [ outline rect ]   │
├───────────────────────┴──────────────────────────────────────┤
│ ■ red │ ■ blue │ ■ yellow  — feature blocks (3), not cards  │
│  title   title    title                                      │
├──────────────────────────────────────────────────────────────┤
```

## Reglas

- Composición asimétrica con bloques de color plano (no gradientes)
- Formas primarias: círculo, cuadrado, triángulo en iconografía
- Esquinas 0–4px; evitar pill buttons salvo círculos intencionales
- Máximo 3 colores primarios + negro/blanco en una vista

## Anti-patterns

- Réplica museo sin función
- Primarios adyacentes sin neutro (vibración)
- Glass / soft shadows

## Mejor para

Creative portfolio, agency, cultural landing — no dashboards densos.
