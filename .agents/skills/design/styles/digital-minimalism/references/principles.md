# Digital Minimalism — Principles

## Structure

- Single background (white or near-white / dark equivalent)
- 1px borders or subtle shadow — pick one system, not both everywhere
- One primary button style per view

## Typography

- One sans + optional mono for code
- Size scale: 12/14/16/20/24/32 — stay on scale
- **Not** Inter by default — choose from design-context

## Color

- Neutral 90% of UI
- One accent for primary actions and links
- Semantic colors only for status

## Spacing

- Generous padding in marketing; tighter in product
- 4px or 8px grid strictly

## Differentiation (required)

Pick ≥1 to avoid slop:

- Distinctive font pair
- Asymmetric layout (swiss influence)
- Strong photography or custom illustration
- Bento grid instead of 3-col features
- Dark mode as primary with refined palette

## Red Flags

```markdown
❌ Hero + 3 features + pricing + footer (unchanged structure)
❌ shadow-sm on every div
❌ rounded-xl on everything
```
