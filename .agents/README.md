# Contexto de marketing (`.agents/`)

Carpeta canónica para el **contexto de producto** que usan las marketing skills del framework.

| Archivo | Uso |
|---------|-----|
| `product-marketing.md` | Posicionamiento, audiencia, ICP, voz de marca — **leer antes** de tareas de marketing tácticas |

Creá o actualizá `product-marketing.md` con la skill **`product-marketing`** (`.cursor/skills/marketing/product-marketing/SKILL.md`).

Las skills importadas de [marketingskills](https://github.com/coreyhaines31/marketingskills) referencian esta ruta; no versionar datos sensibles del cliente en este repo template.
