# Pulse dt-20260702-004

## Cambio

Nueva regla always-on **`17-canvas-first`** (cuerpo en `vitals/specs/rule-bodies/17-canvas-first.body.md`, metadata en `rules-manifest.yaml`):

- **Superficie visual por defecto** para entregas estructuradas — planes, propuestas con alternativas, confirmaciones extensas, análisis/auditorías. El chat queda para conversar: resumen de 2–5 líneas + referencia a la superficie.
- **Mapeo por IDE:**
  - **Cursor → Canvas**: `.canvas.tsx`; leer la skill `canvas` antes de escribir el archivo (workflow, ubicación, SDK, anti-slop).
  - **Antigravity → Artifacts nativos**: plan/propuesta → *Implementation Plan* (pre-ejecución, review del usuario salvo `/fast-lane`); desglose → *Task List*; confirmación extensa → *Walkthrough*. Visibles en Auxiliary Pane / Agent Manager y comentables.
  - **Claude Code → Artifacts publicados** (condicional): páginas HTML vivas en URL privada de claude.ai; solo Team/Enterprise con login y artifacts habilitados — si no, fallback sin insistir.
  - **Codex → según superficie**: App (task sidebar + artifact viewer) recibe archivos autocontenidos; CLI/TUI cae al fallback.
  - **Sin superficie** (CLI puro, CI): fallback de markdown liviano (máx. 1 tabla, headers solo con 3+ secciones reales, resumen ejecutivo primero).
- **Principios**: flat/minimal, jerarquía clara, datos reales sin placeholders, interacción con propósito.
- **Delegación**: bloque `canvas-first` para subagentes con entregas estructuradas.
- Emitida a Cursor (`.mdc`), Antigravity y Claude Code vía `sync-ide`.

Motivación: los volcados de markdown extenso en el chat cargan la vista y cansan al usuario.

`dt-doctor` en verde (catalog, commands-parity, ide-parity OK; warn legacy de Atelier preview, no bloqueante). Investigación Antigravity: blog oficial antigravity.google y codelab de Google confirman el sistema de Artifacts (Implementation Plan, Task List, Walkthrough, screenshots, grabaciones).
