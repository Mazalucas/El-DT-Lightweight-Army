# Swiss Style — Product Shell Template

**Superficie:** dashboard, admin, docs · **Dials:** V=4, M=2, D=7

```text
┌────────┬─────────────────────────────────────────────────────┐
│ Side   │  Breadcrumb / page title                    actions │
│ nav    ├─────────────────────────────────────────────────────┤
│ 240px  │  Filter bar (inline, no card wrapper)               │
│        ├─────────────────────────────────────────────────────┤
│        │  ┌─────────────────────────────────────────────┐   │
│        │  │ Data table / dense content                   │   │
│        │  │ Typography defines hierarchy                 │   │
│        │  └─────────────────────────────────────────────┘   │
└────────┴─────────────────────────────────────────────────────┘
```

## Reglas

- Sidebar: fondo surface, borde derecho 1px, labels 12px caps opcional
- Tabla: zebra sutil o solo líneas horizontales; números tabular-nums
- Toolbar: iconos lineales monocromáticos, 20–24px
- Sin cards anidadas; agrupar con spacing y headings

## Densidad

- Row height 40–48px en tablas
- Padding celda 12px 16px
