# Fluent 2 — Summary

## Tokens

- Brand colors: configurable accent
- Neutral foreground/background ramps
- Border radius: medium default (4–8px)
- Typography: Segoe UI Variable (Windows), system fallback web

## Key Components

- Button: primary, secondary, subtle, transparent
- Input: Field, Textarea, Dropdown, Combobox
- Navigation: Nav drawer, breadcrumb (admin)
- Data: DataGrid, Table — prefer for dense admin

## Layout

- Command bar + content region
- Left nav collapsible on narrow viewports
- Content max-width for reading; full bleed for grids

## Acrylic & Materials

- Acrylic on shell chrome only on web imitations
- Solid surfaces for data-heavy content areas

## Slop Avoidance

```markdown
❌ Fluent blue + acrylic cards on every widget
✅ Tokenized accent, solid data surfaces, v9 components only
```
