# Swiss Style — Principles

## Grid

- 12-column, 8px or 4px baseline
- Margins increase with viewport (not edge-to-edge text on desktop)
- Hang punctuation; align numbers in tables (tabular figures)

## Typography

- Sans-serif grotesque/neogrotesque: Helvetica, Univers, Akzidenz, IBM Plex Sans
- Scale: clear step between h1 → body (≥1.25 ratio)
- Left-align body; centered only for short hero statements

## Color

- Limited palette: 1 accent + neutrals
- Black as ink `#111` or brand dark — not pure #000
- Accent for links and primary action only

## Layout Moves

- **Asymmetric hero:** 7/5 split content vs visual
- **Ragged hierarchy:** one dominant element per viewport
- **Rules and spacing** instead of boxes — borders sparingly

## Anti-Patterns

- Decorative grid lines on every section
- Five font weights in one view
- Centered icon feature row (use offset bento instead)
